# Arulco-Revisited-2026
An update for the Jagged Alliance 2 1.13 mod Arulco Revisited by JAsmine and Beka. 
The mod has been patched to work with the latest 1.13 release but there's a lot of testing to be done.

link to the original version thread:
https://thepit.ja-galaxy-forum.com/index.php?t=msg&th=19441&start=0&

HOW TO INSTALL:

-paste files to folder with JA2 1.13 installed
-open ja2.ini and scroll to the vfs_config section
-paste the following:

; JA2 1.13 AR
VFS_CONFIG_INI = vfs_config.AR.ini

-add a ";" before this line:

VFS_CONFIG_INI = vfs_config.JA2113.ini
